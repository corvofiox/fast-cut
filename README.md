# Fast Cut

**把录好的视频里不要的段落删掉，画质不动，导出很快。**

录屏、直播回放、网课、会议记录——录完往往只需要做一件事：把中间那些废段剪掉。
Fast Cut 就是为这一件事做的。导进来，删掉不要的，导出，完事。

---

## 它能做什么

- **导入就能直接剪**，不用等转码处理完。
- **切成几段、删掉不要的、前后自动接上**，总时长实时变短，跟普通剪辑软件的手感一样。
- **调整切口位置**、**拖动调换段落顺序**、**撤销重做**，全部支持。
- **追加导入**：把多份素材接到同一条轨道上，一次剪完、一次导出，不需要分别处理再自己拼。
- **分段导出**：可以整段拼成一个文件，也可以每段各出一个文件，还可以指定某几段合成一个文件。
- **导出前会先告诉你**：文件名、时长、大概多大、有没有需要你知道的情况，再让你决定。
- **导出后会自己检查一遍**，发现问题宁可报错重来，也不会悄悄给你一个坏文件。
- 支持**换封装格式**（MP4 / M4V / MOV / MKV），不需要你另外找工具转。

## 适合什么场景

- 录了几十分钟的**屏幕录制**，只想留下其中几分钟。
- **直播回放**要掐掉片头片尾和中间的水段、广告段。
- **网课、讲座、会议录像**，要去掉卡顿、走神、无关讨论的部分。
- 手上有**多份素材**（比如分几次录的），想合成一条成片。
- 你**在意画质**，不希望为了剪掉一段就把整条视频重新压缩一遍。
- 你只想要"删段落"这一个动作，**不想为它装一整套剪辑软件**。

## 不适合什么场景

Fast Cut 刻意只做粗剪，以下这些请用别的工具：

- 多轨时间线、转场、滤镜、调色、变速、加水印、字幕烧录；
- 精修、特效、包装类剪辑；
- 视频压缩、格式转换、下载网络视频、录屏本身；
- 需要保存工程文件、下次接着改的项目。

## 下载与安装

到 [Releases](https://github.com/corvofiox/fast-cut/releases) 下载 `Fast-Cut-Setup-0.1.0-x64.exe`，
双击按向导安装即可，**不需要管理员权限**，也**不需要另外安装任何运行环境**。

> 目前没有做代码签名，Windows 首次运行会拦一下，点「更多信息 → 仍要运行」即可。

系统要求：Windows 10 / 11（64 位）。

## 用起来需要知道的几件事

- **默认的剪法是"画面一个像素都不动"**，所以切口会自动落在最接近的位置上——产物开头可能比你选的
  多带一小段。每条片段都会标明多带了多少，导出前的预估里也写着。
- 如果切口必须**精确到某一帧**，勾上「精确模式」：位置准了，代价是切口处极短的一小段会重新压缩一次。
  这一段有多短、要不要接受，界面上都写得很清楚。
- **素材格式不一样也能拼**（比如一份 MP4、一份 MKV），但这时需要你在导出面板里选一下封装与编码；
  没选就点导出会被拦下来并标红提示。
- **全程只读你的源文件**，导出只写到你指定的目录；目标重名、或目标就是源文件时直接拒绝，绝不覆盖。
- 剪辑动作都在键盘上，界面上没有多余的按钮；键位可以自己改。
